# 7. ⚠️ Blockers remaining before runtime

These do not block the neutral skeleton, but they block domain runtime:

1. Scenario contracts have not yet been turned into executable fixtures.
2. Capability Lease has not passed implementation/adversarial validation.
3. Privacy deletion has not been verified through backups, projections, and forks in code.
4. Relationship and commitment reconciliation have not been implemented or tested.
5. M2 → M3 nomination has no executable review workflow.
6. Governed Synthesis exists as a research contract, not as runtime.
7. Responsibility for the operator/deployer/Mentaury must remain attributable in implementation receipts.
8. P0 Event Substrate has not yet been implemented and has not passed the Evidence Gate.
