## Current research frontier

The current high-information frontier has compressed to three families.

### 🌍 1. Epistemic Openness / Coverage

```text
UNCERTAINTY WITHIN THE REPRESENTED POSSIBILITY SPACE
≠
ADEQUACY OF THE REPRESENTED POSSIBILITY SPACE ITSELF
```

A system may be highly confident among the alternatives it currently represents while lacking grounds to claim that the represented set is adequate or exhaustive.

### 💎 2. Bounded Representation / Candidate Access

```text
SOURCE ≠ LOSSY VIEW
NOT REPRESENTED ≠ ABSENT
NOT SURFACED AS A CANDIDATE ≠ IRRELEVANT
```

The strongest residual risk is not merely summary error. A lossy representation may deform the set of candidates that downstream reasoning ever gets to evaluate.

### 🛑 3. Task-Bounded Sufficiency / Reason-Typed Stopping

```text
STOP ≠ TRUTH ESTABLISHED
STOP ≠ SEARCH EXHAUSTED
JUSTIFIED STOP ≠ PERMANENT CLOSURE
```

A system must preserve why cognition terminated and when that basis should be reassessed.

## Strong structural synthesis

> **A cognitive system should be able to act on incomplete internal representations without silently converting the limitations of its own representation, search, memory or internal state into properties of the external world.**

Examples:

```text
my model is confident        ≠ the world is well covered
my summary omits X           ≠ the source lacks X
I stopped searching          ≠ truth is established
many agents agree            ≠ independent evidence multiplied
I remember X clearly         ≠ I remember all relevant history
an old state is remembered   ≠ the old state is current
```

`STATUS: STRONG STRUCTURAL SYNTHESIS · NOT NEW CLOS LAW`.
