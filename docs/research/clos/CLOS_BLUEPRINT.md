## 1. Core cognitive flow

CLOS is not a fixed pipeline. It is a substrate-neutral map of cognitive functions that may loop, branch, run in parallel, stop early or return UNKNOWN.

```text
reality / experience
→ perception
→ representation
→ memory / current model
→ orientation
→ attention / selection
→ reasoning / reconstruction
→ deepen / stop / unknown
→ option formation
→ decision / inhibition
→ authority
→ action / no action
→ consequence
→ revision / learning ↺
```

## 2. Cross-cutting axes

- epistemic status;
- temporal/currentness status;
- provenance/source ownership;
- derivation/dependency;
- authority;
- resource allocation;
- revision and supersession.

## 3. Three current research families

### 🌍 Epistemic Openness / Coverage

```text
confidence inside represented alternatives
≠
adequacy of represented alternatives
```

The architecture must not silently turn closed-world confidence into open-world completeness.

### 💎 Bounded Representation / Candidate Access

```text
source ≠ essence / summary / derived view
omitted ≠ absent
not retrieved ≠ irrelevant
```

Lossy representations may prioritize and may sometimes exclude within a justified scope, but omission must not silently become global negative authority.

### 🛑 Task-Bounded Sufficiency / Stopping

```text
search termination ≠ epistemic closure
answer sufficiency ≠ decision sufficiency ≠ action authorization
```

Termination should retain its material basis and remain reopenable when the basis changes materially.

## 4. Existing distinctions retained

```text
observation ≠ interpretation
hypothesis ≠ fact
proposal ≠ decision
claim ≠ belief
belief ≠ truth
retrieval ≠ evidence
confidence ≠ evidence strength
coherence ≠ truth
current state ≠ historical state
source ≠ reconstruction ≠ revision
consensus ≠ truth
number of agreements ≠ independent evidence count
knowledge ≠ identity
identity ≠ authority
```

## 5. Strong synthesis candidate

> A viable cognitive system must manage bounded and lossy representations, preserve the fact of their incompleteness where material, and still be capable of justified task-bounded stopping without pretending that its internal limitations are properties of the world.

`STATUS: STRUCTURAL SYNTHESIS CANDIDATE · NOT LAW`.

## 6. What CLOS does not establish

CLOS does not currently establish:

- a universal cognition module graph;
- one scalar confidence/coverage score;
- one entropy objective;
- one economic STOP equation;
- a mandatory graph/RAG/vector architecture;
- a reconsolidation module;
- an implicit-memory module;
- a coverage module;
- a universal event-segmentation trigger;
- consciousness, sentience or AGI claims.

## 7. Admission discipline

A new construct must show:

1. distinct function;
2. distinct state/transition implication;
3. non-expressibility using existing constructs;
4. observable failure without it;
5. falsifier;
6. substrate-neutral usefulness;
7. bounded fixture.

If existing vocabulary handles the failure without semantic loss: `NO NEW CONSTRUCT NEEDED`.
