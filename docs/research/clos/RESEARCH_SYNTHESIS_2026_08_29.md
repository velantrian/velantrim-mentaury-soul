## 1. What changed after the latest research cycle

The research cycle compared cross-disciplinary evidence and critiques from multiple AI research passes plus a longitudinal Rosebud memory audit.

The result was compression, not expansion: many candidate mechanisms were demoted to evidence or analogues, while three research families remained high-information.

## 2. Surviving families

### 🌍 Coverage / possibility-space adequacy

Strongest distinction:

```text
UNCERTAINTY WITHIN CURRENT POSSIBILITY SPACE
≠
UNCERTAINTY / IGNORANCE ABOUT WHETHER THAT SPACE IS ADEQUATE
```

Important correction:

```text
MODEL CONFIDENCE IS CONDITIONAL ON THE REPRESENTED MODEL SPACE;
IT DOES NOT ESTABLISH THE ADEQUACY OF THAT SPACE.
```

Open-set recognition, model misspecification and unknown-unknowns work support the phenomenon, but no universal `coverage of reality` scalar is established.

Disposition: `REFINE / CROSSWALK`, not a new module.

### 💎 Lossy representation / candidate discovery

The key risk is candidate-space deformation:

```text
source contains X
→ derived view omits X
→ future task requires X
→ X never enters candidate set
→ downstream evaluator never sees X
```

The correct boundary is not `lossy views may never exclude`.

Instead:

```text
LOSSY VIEW MAY SOMETIMES EXCLUDE WITHIN A JUSTIFIED, SCOPED SUFFICIENCY CONTRACT.
LOSSY OMISSION MUST NOT SILENTLY BECOME GLOBAL NEGATIVE EVIDENCE.
```

Also:

```text
DECLARED LOSS ≠ COMPLETE KNOWLEDGE OF EVERYTHING OMITTED
```

Disposition: strongest current material residual candidate; test with bounded fixtures.

### 🛑 Reason-typed sufficiency / stopping

The research rejects a universal STOP formula.

```text
STOP ≠ TRUTH ESTABLISHED
STOP ≠ SEARCH EXHAUSTED
JUSTIFIED STOP ≠ PERMANENT CLOSURE
```

Possible reasons for stopping include:

- task sufficiency;
- decision sufficiency;
- action sufficiency;
- marginal search cost;
- source unavailability;
- authority/prohibition boundary;
- deadline;
- irreducible uncertainty.

Minimum obligation:

```text
TERMINATION MUST NOT ERASE THE MATERIAL REASON AND STATUS UNDER WHICH COGNITION TERMINATED.
```

Disposition: substantial existing coverage; merge/refine rather than create a stopping subsystem.

## 5. Long-horizon memory evidence from Rosebud

Rosebud was used as a longitudinal behavioural probe, not as authority about its own hidden implementation.

Observed/self-reported risk classes:

- status promotion;
- provenance erosion;
- correction-precedence uncertainty;
- scope/project boundary erosion;
- stale-state resurrection.

Strong pattern:

```text
CONTENT MAY SURVIVE
WHILE
SOURCE / STATUS / CURRENTNESS / CORRECTION HISTORY DEGRADES
```

A bounded mismatch was observed when Rosebud treated `coverage uncertainty` as absent even though the current CLOS documentation already contained that distinction.

This is evidence of a useful failure class:

```text
CONFIDENT PARTIAL RECALL + STALE CURRENT-STATE COVERAGE
```

It is not proof that Rosebud always behaves this way.

## 6. Strong synthesis

> A cognitive system must be able to act on incomplete internal representations without silently converting limitations of its own representation, search, memory or internal state into properties of the external world.

Examples:

```text
my model is confident ≠ the world is fully covered
my summary omits X ≠ the source lacks X
I stopped searching ≠ truth is established
many agents agree ≠ independent evidence multiplied
I remember X clearly ≠ I remember all relevant history
old state remembered ≠ old state current
```

`STATUS: STRONG STRUCTURAL SYNTHESIS · NOT NEW LAW`.
