# Foundation Fix Scope — Owner Direction — 2026-08-19

**Classification:** `OWNER_DIRECTION · BOUNDED_FOUNDATION_FIXES · NO_RUNTIME_GO`

## Intent

Preserve the long-term Mentaury Soul direction as an experimental, increasingly autonomous cognitive system capable of learning from humans, machines, and other systems while preserving provenance and self/non-self boundaries.

The foundation work is intended to make later autonomy more trustworthy rather than replace autonomy with permanent human control.

Core direction:

```text
external experience may inform Mentaury
external experience does not become Mentaury's lived biography
source != self
claim != belief
relation != truth
receipt != truth
reflection != authority
```

## Authorized foundation work

This direction authorizes bounded work that improves:

- truth/status hygiene;
- provenance-preserving representation;
- research protocol integrity;
- exact contract validation;
- canonical serialization/receipt semantics;
- education research contracts that do not infer unstated learner meaning;
- tests that preserve fail-closed/non-authority behavior;
- removal of stale package metadata that falsely presents historical milestones as current engineering status.

## Explicitly not authorized

This direction is not Owner GO for:

- provider/model calls;
- web or private retrieval;
- tools or code execution on behalf of a runtime agent;
- scheduler/background autonomy;
- Evidence Gate truth verdict expansion;
- claim-to-belief promotion changes;
- identity or relationship mutation;
- M3-like autobiographical persistence;
- Action Gate authority;
- autonomous deployment;
- learner cohort execution using real personal data.

Those remain separate future gates.

## Architectural meaning

Human governance gates in the current research phase are scaffolding for safe development. They must not be mistaken for the final cognitive design.

The intended mature direction is that Mentaury internalizes disciplined provenance, uncertainty, self/non-self separation, revisability, and bounded authority as system properties. Human governance remains necessary for external consequential authority, deployment, and legal/organizational accountability unless separately changed by future governance decisions.

## Non-conflation

```text
foundation hardening != retreat from autonomy
autonomy != unrestricted authority
learning from others != becoming others
continuity != immutability
self-development != self-authorization
```
