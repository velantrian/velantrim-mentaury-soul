# EITI Cognitive Input Boundary for Mentaury Soul

Status: **RESEARCH INPUT · SOUL AUTHORITY UNCHANGED**  
Recorded: 2026-08-21

EITI has concrete local mechanisms for retrieval associations, salience/ranking, decay/accessibility, intent/context handling and local learning. These mechanisms can motivate Soul research, but they do not own Soul beliefs, identity, relationships, commitments or cognition state.

```text
EITI memory != Soul belief
EITI association != relationship fact
EITI retrieval salience != identity importance
EITI local learning != self-definition
Crystal evidence != Soul belief
imported heritage != current self
```

## Relevant Soul research questions

### Claim → belief boundary

How can externally retrieved or EITI-local claims enter Soul as claims/candidates without silently becoming beliefs? Promotion must retain source, provenance, contradiction and ownership semantics.

### Associative context

PKG/MOSC-like signals may help choose which existing Soul context is relevant, but co-activation frequency cannot define relationship type, commitment, identity or belief confidence.

### Accessibility and continuity

DAAD-style decay may reduce retrieval accessibility while the underlying Soul-owned state remains unchanged. A forgotten or less-active commitment is not automatically revoked.

### Reflection and learning

EITI learning analysis can propose observations or reflections. Soul must decide whether any proposal affects Soul-owned cognition state. Reflection != evidence; model suggestion != belief; proposal != commitment.

### Velantrim Brain interaction

A bounded cognitive coordinator may request or compose Soul context, but it cannot become a hidden owner of Soul state. Any mutation must use Soul-authorized operations and preserve receipts/provenance where required.

## Negative tests for any future integration

- repeated retrieval never raises belief confidence by repetition alone;
- retrieval salience never changes identity state;
- Crystal/EITI receipts never become identity facts automatically;
- model-generated reflection cannot create a commitment without the appropriate Soul-owned transition;
- stale/decayed retrieval does not silently delete a belief or relationship;
- EITI/Titan cannot issue themselves permission to mutate Soul authoritative state.

EITI is useful empirical evidence for interface/cognitive behavior; Soul remains the bounded owner of self/belief/relationship semantics.
