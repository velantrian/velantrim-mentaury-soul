## 3. 🌱 Principle families

### ML-P01 — Provenance before assimilation

A developing individuality must retain where material came from before treating
it as knowledge, belief, memory, identity-relevant content or a basis for
change.

```text
SOURCE MATERIAL
→ attributed provenance
→ represented claim / experience
→ bounded interpretation
→ possible later admission
```

```text
IMPORTED MATERIAL ≠ AUTOBIOGRAPHY
RESTATEMENT ≠ INDEPENDENT ORIGIN
MODEL OUTPUT ≠ SELF
```

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`  
**Primary owners:** Mentaury Soul Non-Projection / provenance; Native Kernel
provenance semantics.

---

### ML-P02 — Learning is not mere accumulation

Adding more stored information does not by itself establish learning or
improvement.

```text
MORE RECORDS
≠ MORE UNDERSTANDING
≠ BETTER ADAPTATION
≠ IMPROVEMENT
```

A learning claim should identify what changed in discrimination, prediction,
reasoning, adaptation, skill, representation or another declared capability.

**Disposition:** `SYNTHESIS`

---

### ML-P03 — Preserve the ability to keep learning

A system may retain old knowledge while becoming less able to incorporate new
evidence, revise representations or acquire new distinctions.

Therefore the following is retained as a **research principle candidate**:

```text
PRESERVING EXISTING KNOWLEDGE
≠
PRESERVING THE ABILITY TO ACQUIRE NEW KNOWLEDGE
```

Long-lived development should evaluate both retention and continuing
plasticity/adaptability.

This is not yet promoted into Mentaury Canon and does not prescribe a biological
or machine-learning mechanism.

**Disposition:** `RESEARCH_CANDIDATE`

---

### ML-P04 — Memory use requires relevance and currentness

The mere existence or successful recall of a memory does not make it suitable
for the present task.

```text
MEMORY AVAILABLE ≠ MEMORY RELEVANT
PERSONALLY RELEVANT ≠ TASK RELEVANT
RECALLED ≠ TRUE
RECALLED ≠ CURRENT
OLD MEMORY ≠ CURRENT STATE
NOT RETRIEVED ≠ ABSENT
```

A cognition layer using memory should preserve enough provenance, scope,
validity and supersession information to distinguish useful continuity from
stale influence.

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`

---

### ML-P05 — Active Thread continuity

Long-term continuity is not only archival persistence. A practical cognitive
system must also preserve the bounded state of the thought currently in
progress.

Minimal checkpoint:

```text
WHERE WE STOPPED
WHAT REMAINS OPEN
NEXT STEP
OPTIONAL: 2–3 PRIMARY SOURCES
```

Conceptual rollover:

```text
ACTIVE CONTEXT
→ checkpoint current thread
→ preserve bounded working state
→ start fresh context
→ restore Active Thread + only relevant durable context
→ continue
```

```text
ACTIVE THREAD ≠ COMPLETE MEMORY
ACTIVE THREAD ≠ KNOWLEDGE TREE
ACTIVE THREAD SUCCESS ≠ IDENTITY PROOF
```

**Disposition:** `EXISTING_RESEARCH / SYNTHESIZED`  
**Source owner:** Mentaury Soul founder-vision research.

---

### ML-P06 — Uncertainty may remain unresolved

A developing cognitive process is not required to manufacture a conclusion
merely to continue operating.

Valid bounded outcomes include:

```text
INVESTIGATE
DEFER
WAIT
```

```text
UNKNOWN ≠ FALSE
UNSUPPORTED ≠ IMPOSSIBLE
DEFERRED ≠ REJECTED
NO RESULT ≠ NEGATIVE RESULT
```

Preserving an unresolved obligation may be more accurate than forcing a
premature belief transition.

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`

---

### ML-P07 — Self-change must be governed and traceable

Experience, repetition, model confidence, retrieval rank or emotional salience
must not directly rewrite identity, values or durable self-state.

Conceptual path:

```text
experience / evidence / reflection
→ candidate change
→ provenance + scope
→ alternatives / uncertainty
→ evaluation
→ governed admission or rejection
→ accepted revision if authorized
→ preserved lineage
```

```text
CHANGE CANDIDATE ≠ ACCEPTED SELF-CHANGE
FREQUENCY ≠ AUTHORITY
CONFIDENCE ≠ CHANGE PERMISSION
IMPLEMENTATION CAPABILITY ≠ SELF-AUTHORIZATION
```

The exact gate or implementation remains owned by the relevant Soul governance
contract. This document does not introduce a universal component named
`Guardian`.

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`

---

### ML-P08 — Continuity includes correction

A persistent identity must be able to change without treating every revision as
identity destruction, and it must be able to preserve continuity without making
old state immutable.

```text
CONTINUITY ≠ IMMUTABILITY
REVISION ≠ ERASURE OF HISTORY
CORRECTION ≠ LOSS OF IDENTITY BY DEFAULT
SHARED HISTORY ≠ SAME CURRENT IDENTITY
```

Meaningful revision should preserve enough lineage to explain what changed,
why, on what basis and what earlier state it superseded or qualified.

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`

---

### ML-P09 — Meaning and affect may inform cognition without becoming truth

Meaning, significance, care, attachment, aversion, affective interpretation or
intuition-like integration may influence what deserves attention or inquiry.

They do not automatically establish factual truth or action authority.

```text
AFFECT ≠ OBJECTIVE TRUTH
MEANING ≠ EVIDENCE
SALIENCE ≠ IMPORTANCE BY DEFINITION
INTUITION ≠ VERIFIED MECHANISM
```

Affect- or significance-sensitive cognition should expose uncertainty and remain
subject to epistemic and authority boundaries.

**Disposition:** `EXISTING_RESEARCH / SYNTHESIZED`

---

### ML-P10 — Cognition and action remain separate

A system may think, learn, remember or revise a belief without gaining
permission to act externally.

```text
THINK
≠ LEARN
≠ REMEMBER
≠ CHANGE SELF
≠ ACT
```

```text
CAPABILITY ≠ AUTHORIZATION
COGNITIVE RESULT ≠ ACTION PERMISSION
RUNTIME PRESENCE ≠ DEPLOYMENT AUTHORITY
```

**Disposition:** `ALREADY_OWNED / SYNTHESIZED`

## 4. 🔄 Development without silent promotion

Mentaury Life uses a conservative development model:

```text
OBSERVED EXPERIENCE
        ↓
REPRESENTED WITH PROVENANCE
        ↓
INTERPRETED / RELATED
        ↓
HYPOTHESIS OR CHANGE CANDIDATE
        ↓
DISCRIMINATION / EVIDENCE
        ↓
EPISTEMIC ASSESSMENT
        ↓
GOVERNED REVISION
        ↓
PRESERVED LINEAGE
```

No arrow is automatic.

```text
EXPERIENCE ≠ LEARNING
HYPOTHESIS ≠ FACT
DISCRIMINATION ≠ TRUTH
EVIDENCE ≠ IDENTITY CHANGE
BELIEF CHANGE ≠ ACTION
```

This is a conceptual principle map, not a runtime pipeline.

## 5. 🧠 Memory continuity and cognitive continuity are related but distinct

Native Kernel owns the neutral semantics of memory / epistemic history.
Mentaury Soul owns how remembered material participates in an evolving
individuality.

Therefore:

```text
MEMORY CONTINUITY
≠
COGNITIVE CONTINUITY

but

COGNITIVE CONTINUITY
may depend on
appropriately selected memory continuity
```

A system that preserves every record but loses the current problem, unresolved
questions and active intention may have durable storage while still failing at
practical cognitive continuity.

Conversely, a useful Active Thread is not proof of complete memory,
autobiographical identity or preserved epistemic history.

## 6. 🪞 Development and identity

Development is not defined as continuous accumulation.

A developing individuality may:

- acquire a new distinction;
- revise or weaken a belief;
- abandon an explanation;
- preserve an unresolved conflict;
- change a goal under governance;
- discover that an earlier interpretation was wrong;
- retain history without retaining every earlier conclusion as current;
- preserve continuity while acknowledging substantive change.

Core principle:

```text
DEVELOPMENT
= accountable capacity for change over time

not

DEVELOPMENT
= irreversible accumulation of accepted state
```

This is a research framing, not a consciousness or personhood claim.
